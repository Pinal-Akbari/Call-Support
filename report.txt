1. MASTER ARCHITECTURE & ENVIRONMENT OVERVIEW
====================================================================================================
The system is built as an enterprise telephony CRM and Asterisk IP PBX gateway featuring:
  • Two-way Number Masking (Universal BSNL DID) protecting customer and service agent privacy.
  • Agent Console with dynamic queue membership (AMI QueueAdd/QueueRemove) and real-time screen-pop.
  • Caller 360° In-Call Profile: Instant display of past call history, agents spoken with, and audio play.
  • Live Agent Notes & Disposition Engine: Add and persist remarks during live calls in real-time.
  • In-Browser Telephony Simulator: Full audio synthesis (Web Audio API) for zero-setup calling demo.
  • Centralized IP PBX Management: Call queues, IVR auto-attendants, WAV greetings, and DID routing.
  • Automated Call Recording Management with instant in-browser WAV audio playback.
  • Dual runtime support: Seamlessly runs on standalone Apache (XAMPP) and Laravel Artisan Server.
